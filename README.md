SQA Day 1 - Manual Testing (HisabDo)

This repository contains my Day 1 SQA practical work completed during my internship at XICTEK Systems.

For this task, I tested the HisabDo web application, a digital khata/ledger application. I performed manual functional testing on features including user registration, login, guest mode, customer management, income entry, and expense entry.

What's in this repo
Ramna_Raheem_HisabDo_QA_Report_Day1.xlsx - QA test cases and bug reports
Ramna Raheem SQA Internship Day1 Report.pdf - Day 1 testing report
Testing Results
10 test cases: 6 Passed, 3 Failed, 1 Blocked
3 bugs identified:
BUG001 - New customer was not added to the list after submitting "Add Customer"
BUG002 - Income entry was not saved after submitting "Add Income"
BUG003 - Expense entry was not saved after submitting "Add Expense"

All three issues were observed when using a registered account. The same actions worked correctly in Demo Account and Guest Mode.
