# SQA-Day-1-Testing

This repository contains my Day 1 Software Quality Assurance (SQA) practical work.

I tested the HisabDo web application (https://app.hisabdo.app) and performed functional testing on key features such as user registration, customer management, income, and expense management. I created test cases, recorded expected and actual results, identified a functional defect, and documented its severity and priority.

The purpose of this task was to practice manual testing and understand how QA engineers identify, document, and investigate application issues.
